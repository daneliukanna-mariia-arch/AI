
# Система розпізнавання трьох класів на основі мереж Хопфілда та Хеммінга

Вебзастосунок для класифікації растрових зображень на три класи за допомогою рекурентної мережі Хопфілда або двошарової мережі Хеммінга. Програма розбиває зображення на сітку **5×5**, вилучає абсолютні та L2-нормовані вектори ознак і виконує розпізнавання через вебінтерфейс на **Panel**.

---

## Основні можливості

- **Вилучення та обробка ознак:**
  - Автоматичне перетворення зображень у відтінки сірого (Grayscale).
  - Накладання сітки 5×5 (25 рівномірних комірок).
  - Підрахунок кількості темних пікселів (значення < 128) у кожній комірці.
  - Обчислення L2-нормованих векторів ознак.
  - Перетворення ознак у біполярний формат ({-1, +1}) для мережі Хопфілда.
  - Візуалізація сітки 5×5 поверх завантажених зображень.

- **Мережа Хопфілда:**
  - Генерація матриці ваг $W$ розміром 25×25 за правилом Хебба.
  - Нульова діагональ матриці ($w_{ii} = 0$).
  - Асинхронне оновлення станів нейронів.
  - Моніторинг функції енергії $E = -\frac{1}{2} s^T W s$.
  - Виявлення стабільних атракторів або циклів станів.

- **Мережа Хеммінга:**
  - Перший шар: обчислення ступеня збігу вхідного вектора з еталонами (ваги $w_{ij} = x_{ij}/2$, зміщення $\theta = N/2$).
  - Другий шар: конкурентне латеральне гальмування для витиснення слабших сигналів.
  - Детермінований вибір класу-переможця.

- **Інтерактивний інтерфейс (Panel):**
  - Одночасне завантаження трьох еталонів та невідомого образу.
  - Попередня візуалізація зображень та сіток ознак.
  - Виведення матриць ваг, векторів ознак, енергії та відстаней Хеммінга.
