# Task 1: Image Uploader on Panel

## Опис реалізації
Це додаток для завантаження та перегляду зображень, реалізований за допомогою фреймворку **Panel**. Додаток дозволяє завантажувати файли формату `jpg`, `jpeg`, `png`, `webp` та одразу переглядати їх на екрані.

## Використані бібліотеки
- Python 3.x
- Panel
- Pillow (PIL)
