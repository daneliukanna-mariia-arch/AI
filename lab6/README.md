# Лабораторна робота №6

## Склад проєкту
- `lab6.py` — запуск трьох підходів;
- `data/` — чотири документи бази знань і спільний тестовий набір;
- `requirements.txt` — Python-залежності.

## Запуск на Mac
1. Встанови Ollama з https://ollama.com/ та запусти її.
2. Відкрий Terminal і перейди в папку проєкту.
3. Виконай:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ollama pull llama3.2
   python lab6.py
   ```
4. Програма надсилає запити до локальної LLM для Prompt, RAG та few-shot.
5. Фактичні відповіді й точність зберігаються у `results.csv`.

**Примітка:** few-shot — лише імітація Fine-tuning. Це не справжнє додаткове навчання моделі.
Фактичні результати можуть відрізнятися від демонстраційних чисел у звіті. Для чесного звіту
потрібно запустити скрипт і перенести отримані результати з `results.csv`.
