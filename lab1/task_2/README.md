# Система розпізнавання образів за методом порівняння з еталоном

Вебдодаток для класифікації чорно-білих зображень на основі нормованих векторів ознак із використанням бібліотеки **Panel** та **Pillow**.

## 📌 Опис проєкту
Програма реалізує алгоритм розпізнавання образи методом еталонів:
1. Зображення поділяється на сітку **5×5**.
2. Для кожної комірки обчислюється кількість чорних пікселів (абсолютний вектор ознак).
3. Формується нормований вектор ознак шляхом ділення кількості чорних пікселів у комірці на їх загальну кількість.
4. Порівняння невідомого образу з 3 еталонами здійснюється за обраним типом норми:
   * **Евклідова норма**
   * **Норма Чебишева**
   * **Манхетенська норма**
5. Система автоматично визначає найменшу відстань та виконує класифікацію.
