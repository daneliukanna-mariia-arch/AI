# Система розпізнавання образів

Вебдодаток для класифікації та розпізнавання зображень на основі методу мінімальної відстані до центрів кластерів. Проєкт реалізовано на Python з використанням бібліотеки **Panel** для побудови інтерактивного інтерфейсу, а також **NumPy** та **Pillow (PIL)** для обробки зображень.

---

## 📌 Основні можливості

* **Підтримка форматів:** Завантаження зображень у форматах `.png`, `.jpg`, `.jpeg`, `.bmp`.
* **Виділення ознак:** Автоматичне розбиття кожного зображення на сітку **4×5** (рядків/стовпців) із підрахунком кількості пікселів заданої інтенсивності (темних пікселів) та побудовою абсолютного й нормованого векторів.
* **Навчання системи:** Обробка трьох класів зразків (по 10 зображень у кожному) та розрахунок **центрів кластерів** для них.
* **Візуалізація:** Генерація зображень із накладеною червоною сіткою 4×5 та виведення повної статистики і векторів у вигляді зручних Markdown-блоків на всю ширину екрана.
* **Розпізнавання:** Визначення приналежності невідомого зображення до одного з трьох класів за допомогою розрахунку евклідової відстані до центрів кластерів.

---

## 🛠 Технології

* **Python 3.10+**
* **Panel** — для створення веб-інтерфейсу.
* **NumPy** — для математичних обчислень та роботи з векторами.
* **Pillow (PIL)** — для завантаження, конвертації та малювання на зображеннях.
