# Система побудови вектора ознак (Panel App)

Вебдодаток для аналізу чорно-білих зображень (формату BMP), який розбиває зображення на сітку 5×5, обчислює кількість чорних пікселів у кожній комірці та генерує **абсолютний** і **нормований** вектори ознак. Додаток побудований на базі бібліотеки **Panel** з використанням **Pillow** та **NumPy**.

## Можливості

* **Завантаження зображень:** Підтримка завантаження файлів формату BMP та інших зображень.
* **Візуалізація сітки:** Автоматичне накладання червоної сітки 5×5 поверх завантаженого зображення.
* **Розрахунок ознак:** 
  * *Абсолютний вектор:* точна кількість чорних пікселів у кожній із 25 комірок.
  * *Нормований вектор:* відносна частка чорних пікселів у кожній комірці відносно загальної кількості чорних пікселів на зображенні (з округленням до 4 знаків).
* **Інтерактивний інтерфейс:** Зручна панель керування на основі Python (Panel).
